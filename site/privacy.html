Privacy Policy

Effective date: 13 November 2026. This policy covers mailbox-agent, a personal Gmail organization tool.

1. Who operates this app

mailbox-agent is a personal tool operated by one person for their own mailbox. It is not a service offered to the public. Only the owner's own Gmail account, bilal072ahmad@gmail.com, is authorized. No other user's mailbox is accessed.

2. What the app requests from Google

mailbox-agent authorizes with a single Google OAuth scope:

  • https://www.googleapis.com/auth/gmail.modify — read mail, and change labels, the read state, and the inbox (archive) state of messages.

With this scope the app reads message metadata and content, applies labels, marks messages read, and archives mail. The app never sends, replies to, forwards, trashes, or deletes email.

3. Companion tool on the same account

The same Google account also authorizes a separate Google Workspace skill, run by the same owner for the same account. Its OAuth token may carry additional scopes, including gmail.readonly and gmail.send, plus other Google Workspace scopes such as Calendar, Drive, Google Sheets, and Google Docs. Those scopes belong to the companion skill. mailbox-agent itself uses only gmail.modify and does not access those other services.

4. Data the app reads

  • Message metadata: sender, recipient, subject, date, and label state.
  • Message content: headers and body text of inbox messages, read to classify and summarize them.
  • Thread state for recent threads, to detect follow-ups.

5. Data the app stores, and where

Everything the app stores stays on the owner's own private server. The app writes nothing to any cloud service. Stored locally:

  • Processed message IDs — so each message is handled once. The list is capped and old entries roll off.
  • Contact records — senders seen for the first time.
  • Follow-up records — threads awaiting a reply.
  • Label mappings — label names mapped to Gmail label IDs.
  • An append-only audit log — one line per action taken.
  • Run logs and, when extraction is enabled, saved attachment files.

No mailbox data is copied to any third-party service. The only network calls the app makes are to the Gmail API on Google's own endpoints.

6. Retention

Local state is kept for as long as the app runs. Processed message IDs are capped, so the oldest entries are dropped first. The audit log and run logs are append-only files on the owner's machine; the owner deletes them directly when they are no longer wanted. No copies exist anywhere else. Deleting the app's files removes all stored data.

7. Sharing and sale of data

mailbox-agent does not sell, rent, share, or disclose mailbox data to any person or company. There is no advertising, no analytics, and no tracking code in the app or on this site.

8. Your control over access

You can revoke the app's access at any time:

  1. Open your Google Account at myaccount.google.com/permissions (Google Account → Security → Third-party apps with account access).
  2. Find the app entry for mailbox-agent and choose Remove access.

Revoking stops all further access immediately. Revoking does not delete the local state files on the owner's machine; those are deleted by the owner directly.

9. Changes to this policy

Updates to this policy are posted on this page with a new effective date.
