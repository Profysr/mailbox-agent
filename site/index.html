Your inbox, sorted by rules you wrote.

mailbox-agent is a personal Gmail organizer. It runs hourly on its owner's own server, sorts incoming mail into labels, and leaves everything else exactly as it is. It never sends, replies to, or deletes email.

Read the privacy policy Contact

What it does

mailbox-agent is a single-person tool. It is not a bulk mailing service, not a CRM, and not a shared team inbox. Exactly one account is authorized: the owner's own.

  • Rule-based classification

    Sender and subject rules decide a category. The first matching rule wins. Unknown senders land in a safe catch-all and stay in the inbox.

  • Automatic labeling

    Matched mail receives a Gmail label: Banking, Security, Finance-Tax, Receipts, Careers, Jobs, Newsletters, Personal, Subscriptions, or Unsorted.

  • Mark read and archive

    Rules may mark mail read and remove it from the inbox. Archiving is optional per rule and fully reversible. Nothing is deleted.

  • Follow-up detection

    The tool flags threads that need your reply and threads where you wait for a reply. Bulk senders and notifications are ignored.

  • Extractive summaries

    Each run produces short summaries of kept mail. The summaries come from the message text itself. No AI model is involved.

  • Run digests

    Every run prints a plain-text digest of what it did. An empty digest means nothing changed.

How it works

  1. Hourly pass A scheduled job starts the tool once per hour. It reads message metadata from the inbox.
  2. Classification Each message is matched against the ruleset. The first match wins. Unknown senders fall to the Unsorted catch-all and stay in the inbox.
  3. Actions The tool adds labels, clears the unread flag, and archives mail only where a rule allows it. Every action is reversible.
  4. Local state Processed message IDs, contacts, and follow-up threads are recorded on the owner's machine. Each message is handled once.
  5. Audit and digest The tool appends one line per action to a local audit log and prints a short run digest.

New labels are created only after they are explicitly approved in the configuration. Mail from unapproved categories is left untouched.

What it never does

  • Never sends email.
  • Never replies to or forwards email.
  • Never trashes or deletes email.
  • Never shares, sells, or uploads mailbox data.

Data and privacy

All state stays on the owner's own machine. No mailbox data is sold or shared with anyone. You can revoke the app's access at any time from your Google Account security page. The privacy policy lists the exact Google scopes requested, what is stored, and where.
